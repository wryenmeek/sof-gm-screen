# Server-Isolated Player Companion & Native OS Dictation Input

The Player Companion is served via a dedicated server-side `doGet(e)` branch (`?view=companion`) rather than a client-side CSS `@media (max-width: 768px)` fork inside `Index.html`, and GM-only `Code.gs` RPCs are guarded by a `ScriptProperties` token check (`assertGmAccess_`). Under `Execute as: Me`, shipping the full GM Screen DOM to mobile devices exposes Encounter Dossiers and Table Notes whenever a player rotates their phone to landscape or calls public `google.script.run` methods from DevTools. Furthermore, because Google Apps Script's outer `script.google.com` wrapper omits `allow="microphone"` on `#sandboxFrame` (blocking `webkitSpeechRecognition` and `getUserMedia` with `NotAllowedError` on mobile browsers), the Push-to-Talk Rules Sniffer uses a tap-to-focus search input backed by native iOS/Android OS keyboard voice dictation with a 900ms auto-query debounce into MiniSearch, retaining `webkitSpeechRecognition` only as a progressive enhancement where permitted.
