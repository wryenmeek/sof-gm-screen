# Zero-Token Attendance Quorum & On-Demand Narrative Promise Extraction

Campaign scheduling governance (`auditCalendarQuorum`) runs as a deterministic Wednesday 12:00 PM Apps Script trigger with zero LLM token spend, whereas post-session Narrative Promise extraction (`extractNarrativePromises`) runs strictly on demand via an explicit Table Notes action (`#extract-promises-btn`) rather than on the 60-second Table Notes auto-save timer. Because recurring Google Calendar series often exist before guest lists are populated or carry human-authored meeting notes, `auditCalendarQuorum` returns `SKIPPED_NO_GUESTS` when `0` guests are invited (preventing false-positive cancellations) and confines its 2d8 Weather Hexflower forecast and reschedule notices to a bounded `<!-- SOF_QUORUM_AUTOMATION:START/END -->` block so existing event descriptions are preserved. Conversely, running `gemini-2.5-flash` promise extraction on every 60-second keystroke auto-save would burn API quota on half-typed sentences and race concurrent saves; triggering extraction on demand with a strict JSON `responseSchema`, `LockService` serialization, and paginated case-insensitive deduplication against both open and completed Google Tasks guarantees idempotent task creation.
