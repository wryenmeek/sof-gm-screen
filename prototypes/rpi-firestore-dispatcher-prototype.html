Guided Architectural Scenarios
Scenario 1: Happy Path: The table says "Roll for Initiative!" Local ONNX model on the Raspberry Pi classifies combat in 420ms (well under the 1,500ms budget). The Edge dispatcher writes directly to Cloud Firestore in 24ms. Both GM Screen and Player Companions receive onSnapshot events instantly.

Scenario 2: Cloud Firestore Timeout / Flaky WAN: Internet connection to Google Cloud experiences high jitter or hangs (>800ms budget). The edge dispatcher times out on Firestore and immediately falls back to posting an outbound HTTP JSON payload to the local GM Screen LAN webhook (192.168.1.100:8080/api/cue), keeping music transitions instant.

Scenario 3: Total Table Network Outage: Both home Wi-Fi and cloud internet drop at a convention. The edge dispatcher fails to reach Firestore, fails to reach the local webhook, and automatically spools the cue into session_audio_manifest.json. When internet recovers, the queue is drained automatically.
